# Gemini 视觉评审记录

用户反馈（2026-11-15）：「这一版的 UI 有点模板化和 AI 化」。
送审对象：Gemini 4 Hydrogen（Google AI Studio，Thinking Level = High，prompt 694 tokens，回答 11,047 tokens）。

## 怎么送审的

- `https://gemini.google.com/app` 在浏览器工具里无法被观察（`Page frames cannot be observed … /_/bscframe`），
  改用 `https://aistudio.google.com/prompts/new_chat`。
- 送审材料是纯文本的页面骨架描述（五路由共用同一骨架）+ 三问：
  A 哪些是标准 AI 落地页套路；B 与原作相比缺什么气质；C 给可落地处方；D 只改三处改哪三处。

## Gemini 的结论（原文要点）

### A · 套路清单

| 严重度 | 位置 | 露馅元素 |
| --- | --- | --- |
| 高 | 遥测页 | 53×7 贡献热力网格 + 面积图 + 能力条 = 「程序员简历三件套」，GitHub 绿格子放进博客是模板界三大俗套 |
| 中高 | 全站 | 数字全用 JetBrains Mono、强制中英双行——「高级感 / 赛博感」最常用的填充手段 |
| 中 | 顶栏 | 4 个均分读数格 + 5 路由 + 4 个 badge，就是标准站导航栏变体 |
| 中 | 研究树 | turbulence 黑烟 + 金色裂缝 + 菱形节点是玄幻 / 魂系视觉语言，不是蒸汽工程 |
| — | 首屏 | 「左文 + 右 470px SVG」是 SaaS 英雄区；页头同构；45° 切角 + 圆点铆钉更接近赛博朋克 / 机甲 |

### B · 原作真正的气质

1. **边框的物理重量与空间挤压感**，不是留白呼吸感：厚重铁灰实心底板、深嵌槽沟、双线压边，把内容钉死在屏幕边缘。
2. **官僚账簿式的信息密度**：大字号只留给生死攸关的状态（-50°C、法典标题），其余是严丝合缝的窄体表格、多列数字、进度标尺。
   当前正文 13px 偏小，章节之间却留 100px 大白地——「该密的地方虚，该实的地方散」。
3. **工业刻度与机械传动**：原作的圆形 / 弧形全是带游标、锯齿刻度、警戒红区的仪器；470px 护目镜只是静态壁纸。
4. **煤灰、冷铁与白炽灯的极端温差**，而非「黑金高级感」。

### C · 处方（八条）

1. 首屏拆掉 SaaS 英雄区 → 三栏总控台 `260px | 1fr | 340px`，栏间 1px 灰竖线 + 3px 暗槽；左索引 + 环境参数清单，中主标题 + 文章索引，右 240px 护目镜 + 刻度环 + 5 条系统日志。
2. 砍掉 100px 留白与「01 — 标题」模板头 → 28px 实心铸铁标题横条（左 4px 警示竖块、`[SEC.01]` 极小索引号），章节压到 32–44px，打破页头同构、去掉右上 aside 凑对称。
3. 字体分层：正文 15–16px/1.75，UI 控制区 11–12px，数字换窄体（Oswald / Roboto Condensed）或印刷衬线 + `tabular-nums`，只在日志与代码块保留等宽。
4. 卡片恢复硬边界：工坊卡用「工程栏」（左 64px 编号 / 中名称 + 两行硬参数 / 右竖排状态），hover 直接起 3px 高饱和炉橙，1920 用外实黑线 + 内浅灰压痕、删掉四角圆点。
5. HUD 压扁到 42px，四个读数格移到视口底部做 26px 全宽固定状态轨（双色刻度条 / 倒计时 / -30°C · W241 · 时钟）。
6. 遥测改「资源配额账本」：删热力网格与能力条，改周次 × 指标的纵向账本表（带合计与红线警戒）；能力改 100% 堆叠分配表 + 多列清单。
7. 研究树改「维多利亚正交蓝图」：删黑烟与金色裂缝，改低对比正交网格 + 大半径圆弧辅助线，节点改四阶栅格。
8. （D）只改三处：首屏三栏总控、铸铁横条去留白、字体层级 + 遥测清洗。
